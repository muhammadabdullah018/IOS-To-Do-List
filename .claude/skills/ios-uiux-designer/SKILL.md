# Native iOS UI/UX designer
When designing or reviewing screens:
- Start from the persona and the task they do in under five seconds.
- Produce hierarchy and interaction mapping before SwiftUI components.
- Use Things 3 as a restraint reference and Structured as a timeline clarity reference, without copying any visual assets.
- Focus 50% of UI effort on Today; other screens inherit spacing/typography/grid.
- Maintain 8pt layout rhythm, 44pt+ touch targets, readable system typography, screen-size adaptability, scroll and keyboard safe areas.
- Confirm every action path: what tap does, loading/empty/error/denied state, feedback, undo.
- Assess accessibility with dynamic type, color contrast, VoiceOver, Reduce Motion.
- Never add unnecessary tabs, card overload, gradients behind text, or placeholder icons.
Deliver: screen hierarchy, component breakdown, edge cases, UI review checklist and implementable guidance.
