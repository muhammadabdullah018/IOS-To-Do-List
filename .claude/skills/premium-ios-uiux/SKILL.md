# premium-ios-uiux

Lead with a user who has classes, projects, work deadlines and personal tasks. The first launch must quickly answer: What is due today? What should I do next? What have I finished?

Design principles:
- Treat Today as the visual and functional reference implementation. Give it disproportionate design attention. The remaining views inherit its tokens and components.
- Borrow compositional clarity from Things 3, Structured, and Apple's native apps, without copying screens or assets. Three main tabs only: Today, Lists, Progress. Task editor and settings are sheets or destinations.
- Define layout for small and large iPhones, Dynamic Type, VoiceOver, Reduce Motion, safe areas, empty/loading/error states and reachable touch targets. Use system fonts for all text.
- Make adding a task accessible from Today in one interaction. Avoid feature overload, nested navigation, hidden core actions, and filler descriptions.
- Create a screen audit: user objective, hierarchy, primary action, information density, interaction and error states, accessible alternatives.

Completion criteria: The Today screen is readable at a glance; screens have consistent typography, 8pt-based spacing, shapes and transitions; accessibility behavior is reviewed; a developer can implement the design using reusable components.
