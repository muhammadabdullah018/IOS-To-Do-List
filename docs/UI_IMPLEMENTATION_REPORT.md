# UI implementation report

Reference: the 10-screen Skyday board (pixel sky, `#0593C6` / `#FCFFFF` / `#D83995`, Light Sky `#D7F2FF`, Soft Pink `#FFE6F4`). All UI is native SwiftUI; no screenshot images are used as UI. Sky header art is original, generated by `Tools/make_sky_art.py`; sprites are character grids in `Skyday/DesignSystem/PixelArt.swift`.

| # | Screen | SwiftUI file | Reached from | Real screenshot | Differences from reference |
|---|---|---|---|---|---|
| 1 | Launch | `Info.plist` `UILaunchScreen` + `LaunchBackground` | app start | — | system launch screen (plain sky colour); no artificial splash delay, as the spec asks |
| 2 | Today | `Features/Today/TodayView.swift` | tab 1 | `02_today.png` | header scene changes day/sunset/night by hour; torii island art instead of the board's exact drawing |
| 3 | Lists | `Features/Lists/ListsView.swift`, `ListDetailView.swift` | tab 2 | `03_lists.png` | adds search and an Inbox list |
| 4 | Progress | `Features/Progress/ProgressScreen.swift` | tab 3 | `04_progress.png` | adds daily-goal stepper and 5-week grid; badges moved to Streaks |
| 5 | Add Task | `Features/Task/TaskEditorSheet.swift` (create) | `+` buttons, empty state | `05_add_task.png` | quick date chips; native toggles/pickers instead of chevron rows |
| 6 | Task Detail | `TaskEditorSheet.swift` (edit) | tap a task | `06_task_detail.png` | same sheet as Add, with Mark as complete and delete |
| 7 | Calendar | `Features/Plan/PlanView.swift` | Today calendar button, progress card | `07_calendar.png` | week strip + agenda (iOS) rather than full month grid; web demo has the month grid |
| 8 | Streaks & Achievements | `Features/Progress/StreaksView.swift` (new) | Progress streak bubble / "Streak & Achievements" row | `08_streaks.png` | milestone track uses flame icons; rule text is supportive, no reset shaming |
| 9 | Settings | `Features/Settings/SettingsView.swift` | Progress gear | `09_settings.png` | no "Appearance" or "Widgets" rows because they would do nothing (app is light-only; widget is added from the Home Screen) |
| 10 | Empty State | `DesignSystem/Components.swift` `EmptySkyState` + `Sprite.emptyIsland` | Today with no tasks | `10_empty_state.png` | CTA uses deep sky (4.9:1) instead of hot pink for text contrast |

Shared components: `SkyHeader`, `SkyTitle`, `SkyCircleButton`, `StreakBadge`, `ProgressSummaryCard`, `SectionAddHeader`, `StatCard` (`Cards.swift`); `TaskRow`, `SkyCheckbox`, `Chip`, `EmptySkyState`, `UndoToast` (`Components.swift`); `PixelSprite`, `PixelBurst` (`PixelArt.swift`); tokens in `Theme.swift`.

Accessibility: every control has a label; checkboxes read "Complete <title>"; cards combine into one element; 44pt targets; `accessibilityReduceMotion` switches animations to fades. Not yet done: a recorded VoiceOver walk-through and AX5 screenshots.

Screenshots come from the XCUITest `testScreenshotTour` on the CI simulator, exported from the `.xcresult`.
