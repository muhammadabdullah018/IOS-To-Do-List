# UI implementation report

Reference: the 10-screen Skyday board (pixel sky, `#0593C6` / `#FCFFFF` / `#D83995`, Light Sky `#D7F2FF`, Soft Pink `#FFE6F4`). All UI is native SwiftUI; no screenshot images are used as UI. Sky header art is original, generated by `Tools/make_sky_art.py`; sprites are character grids in `Skyday/DesignSystem/PixelArt.swift`.

## Motion (from the three reference clips)
| Reference clip | iOS | Web demo |
|---|---|---|
| Icon morph (globe, moon, sun) | Today header sun/moon/haze symbol uses `.contentTransition(.symbolEffect(.replace))` + bounce; launch transition morphs moon to sun | `MorphIcon` SVG (one circle + sliding mask + rays) plays globe, moon, sun in the header and splash |
| Pill tab bar with ripple and active-icon pop | kept the native tab bar (VoiceOver, UI tests, iOS conventions) | floating dark pill, sliding highlight, ripple on tap, active icon scales up |
| Staggered card list | `staggeredAppear(index)` on Today rows and list cards | `.stagger` rise animation with per-row delay |
The clips are jitter.video templates with a watermark, so they were recreated in code, not embedded. All motion stops under Reduce Motion / `prefers-reduced-motion`.

Shared components: `SkyHeader`, `SkyTitle`, `SkyCircleButton`, `StreakBadge`, `ProgressSummaryCard`, `SectionAddHeader`, `StatCard` (`Cards.swift`); `TaskRow`, `SkyCheckbox`, `Chip`, `EmptySkyState`, `UndoToast` (`Components.swift`); `PixelSprite`, `PixelBurst` (`PixelArt.swift`); tokens in `Theme.swift`.

Accessibility: every control has a label; checkboxes read "Complete <title>"; cards combine into one element; 44pt targets; `accessibilityReduceMotion` switches animations to fades. Not yet done: a recorded VoiceOver walk-through and AX5 screenshots.

Screenshots come from the XCUITest `testScreenshotTour` on the CI simulator, exported from the `.xcresult`.
